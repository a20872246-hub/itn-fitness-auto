  방법 1: 소스코드로 실행 (개발/수정용)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [macOS]
    1. 프로젝트 폴더를 원하는 위치에 복사
    2. launcher.sh 더블클릭 (또는 터미널에서 ./launcher.sh)
    3. 처음 실행 시 Python, VLC, 패키지 자동 설치

  [Windows]
    1. 프로젝트 폴더를 원하는 위치에 복사
    2. launcher.bat 더블클릭
    3. 처음 실행 시 패키지 자동 설치
    * Python 3 필수 설치: https://www.python.org/downloads/
      설치 시 "Add Python to PATH" 반드시 체크!
    * VLC 필수 설치: https://www.videolan.org/vlc/

  코드 수정 후 다시 실행하면 바로 반영됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  방법 2: 실행 파일로 배포 (일반 사용자용)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [macOS에서 빌드]
    1. 터미널에서 프로젝트 폴더로 이동
    2. ./build_macos.sh 실행
    3. dist/ 폴더에 "ITN Fitness 안내방송.app" 생성됨
    4. ITN_Fitness_v1.0.0_macOS.zip 파일로 배포

  [Windows에서 빌드]
    1. 프로젝트 폴더에서 build_windows.bat 더블클릭
    2. dist\ 폴더에 "ITN Fitness 안내방송" 폴더 생성됨
    3. 해당 폴더를 ZIP으로 압축하여 배포

  * 빌드는 해당 OS에서 직접 실행해야 합니다
    (macOS에서 Windows용 빌드 불가, 반대도 마찬가지)
  * VLC Media Player는 별도 설치 필요

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  BGM 무한재생
    - 유튜브 URL/재생목록 입력으로 배경음악 재생
    - 광고 없이 오디오만 스트리밍, 볼륨 조절

  자동 안내방송
    - 요일/시간별 스케줄 자동 방송
    - 6종 한국어 AI 음성 (여성 2종, 남성 4종)
    - 음성 속도 조절 (-30% ~ +50%)
    - TTS 자동 생성 또는 MP3 파일 업로드

  볼륨 덕킹
    - 안내방송 시 BGM 자동 페이드 다운/복귀

  원격 제어
    - 스마트폰 브라우저에서 원격 조작
    - 접속 주소: http://[PC IP]:8585

  긴급 방송
    - 원클릭 긴급 방송 (화재 대피 등)

Q: [macOS] 앱이 실행되지 않아요
A: Finder에서 앱을 마우스 우클릭 -> "열기" 선택

Q: BGM이 재생되지 않아요
A: VLC 설치 확인, 유튜브 URL 유효성 확인, 인터넷 확인

Q: 안내방송 소리가 안 나와요
A: 안내방송 탭 -> "테스트 재생" 클릭, 시스템 볼륨 확인

Q: [Windows] Python 관련 오류
A: Python 재설치 후 "Add Python to PATH" 체크 확인

Q: 원격 제어가 안 돼요
A: 설정 탭에서 원격 제어 활성화, 같은 와이파이 연결 확인
