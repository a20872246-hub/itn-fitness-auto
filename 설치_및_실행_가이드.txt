초간단 실행 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ZIP 파일 압축 해제
   "ITN_Fitness_v1.0.0_macOS.zip" 더블클릭

2. 앱 실행
   "ITN Fitness 안내방송.app" 더블클릭

3. 끝!
   - 터미널이 자동으로 열립니다
   - Python, VLC, FFmpeg 자동 확인 및 설치
   - 안내방송 시스템이 자동으로 실행됩니다


사전 설치가 필요한 프로그램
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

앱이 아래 프로그램을 자동으로 확인하고 설치를 안내합니다:

  1. Python 3 -> 자동 설치 (Homebrew 경유)
  2. VLC Media Player -> 자동 또는 수동 설치 안내
  3. FFmpeg -> 자동 설치 (Homebrew 경유)

모두 앱 첫 실행 시 자동으로 처리됩니다!


주요 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  BGM 무한재생
    - 유튜브 URL 입력으로 배경음악 재생
    - 광고 없이 오디오만 스트리밍
    - 볼륨 조절 가능

  자동 안내방송
    - 요일/시간별 스케줄 설정
    - 직접 작성한 커스텀 멘트 관리
    - 안전/위생, 수업, 이벤트, 긴급 카테고리
    - TTS 자동 음성 생성 또는 파일 업로드

  볼륨 덕킹
    - 안내방송 시 BGM 자동 페이드 다운
    - 방송 종료 후 자동 복귀

  원격 제어
    - 스마트폰 브라우저에서 원격 조작
    - 즉시 방송, BGM 제어, 스케줄 확인
    - 접속 주소: http://[헬스장PC IP]:8585

  긴급 방송
    - 원클릭 긴급 방송 (화재 대피 등)
    - BGM 즉시 정지 + 최대 볼륨 송출


처음 실행 시 소요 시간
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  모든 프로그램이 설치된 경우: 1-2분
  Python/VLC 자동 설치 필요한 경우: 5-10분
  두 번째 실행부터: 즉시 실행! (5초 이내)


원격 제어 사용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 설정 탭에서 "원격 제어 활성화" 체크 후 저장, 재시작
  2. 앱 실행 시 터미널에 표시되는 주소 확인
     예: http://192.168.0.10:8585
  3. 스마트폰 브라우저에서 해당 주소 접속
     (같은 와이파이에 연결되어 있어야 합니다)
  4. 비밀번호 설정 (최초 접속 시)
  5. 대시보드에서 BGM, 방송, 스케줄 원격 제어


문제 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 앱을 더블클릭해도 실행되지 않아요
A: Finder에서 앱을 마우스 우클릭 -> "열기" 선택
   (macOS 보안 설정 때문입니다)

Q: BGM이 재생되지 않아요
A: 1. VLC Media Player가 설치되었는지 확인
   2. 유튜브 URL이 유효한지 확인
   3. 인터넷 연결 확인

Q: 안내방송 소리가 나오지 않아요
A: 1. 안내방송 탭에서 "테스트 재생" 버튼 클릭
   2. 또는 "TTS 생성" 버튼으로 음성 파일 생성
   3. 시스템 볼륨 및 출력 장치 확인

Q: 원격 제어가 접속되지 않아요
A: 1. 설정에서 원격 제어가 활성화되어 있는지 확인
   2. 같은 와이파이에 연결되었는지 확인
   3. 앱 실행 중인지 확인

Q: "ModuleNotFoundError" 오류
A: 앱을 다시 실행하면 자동으로 재설치를 시도합니다.
