================================================
  ITN Fitness 자동 안내방송 시스템
  Windows 설치 가이드 (처음 사용자용)
================================================


[STEP 1] VLC Media Player 설치 (필수)
------------------------------------------------
  1. 아래 주소를 인터넷 브라우저에 입력
     https://www.videolan.org/vlc/

  2. "Download VLC" 큰 버튼 클릭

  3. 다운로드된 파일 실행

  4. 설치 화면에서 계속 "다음" 클릭하여 설치 완료
     (설정은 건드리지 말고 기본값 그대로!)


[STEP 2] Python 설치 (필수)
------------------------------------------------
  1. 아래 주소를 인터넷 브라우저에 입력
     https://www.python.org/downloads/

  2. "Download Python 3.xx.x" 큰 버튼 클릭

  3. 다운로드된 파일 실행

  4. !!중요!! 설치 첫 화면 하단에
     "Add Python to PATH" 체크박스를 반드시 체크!

  5. "Install Now" 클릭하여 설치 완료


[STEP 3] 프로그램 실행
------------------------------------------------
  1. 전달받은 ZIP 파일의 압축을 풀기

  2. 압축 푼 폴더 안에서 launcher.bat 를 더블클릭

  3. 처음 실행 시 필요한 파일을 자동으로 설치합니다
     (1~2분 정도 기다려 주세요)

  4. 설치가 끝나면 프로그램 창이 자동으로 열립니다!

  5. 다음부터는 launcher.bat 더블클릭만 하면 바로 실행됩니다


================================================
  자주 묻는 질문
================================================

Q: "Windows의 PC 보호" 경고가 뜨면?
A: "추가 정보" 클릭 -> "실행" 클릭

Q: 검은 창이 뜨고 바로 꺼지면?
A: Python 설치 시 "Add Python to PATH" 체크를 안 한 경우입니다
   Python을 삭제 후 다시 설치해 주세요 (STEP 2 다시)

Q: BGM이 안 나오면?
A: VLC가 설치되어 있는지 확인 (STEP 1 다시)
   인터넷이 연결되어 있는지 확인

Q: 안내방송 소리가 안 나오면?
A: 컴퓨터 스피커 볼륨 확인
   인터넷 연결 확인 (음성 생성에 인터넷 필요)
